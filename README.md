# Deskly Landing Page

Official landing page for [Deskly](https://github.com/Vishal-770/Deskly) - the open-source desktop app for VIT Chennai students.

## 🚀 Live Site

[deskly.vishaldev.space](https://deskly.vishaldev.space)

## 🛠️ Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lenis** (Smooth scrolling)
- **Lucide Icons**

## 💻 Development

```bash
npm install
npm run dev
```

Visit [localhost:3000](http://localhost:3000)

## 📦 Build

```bash
npm run build
npm start
```

## ✨ Features

- Fully SEO optimized with structured data
- Auto-generated sitemap and robots.txt
- Open Graph & Twitter Card support
- Mobile-first responsive design
- Smooth animations and interactions
